Every example names the screen and the file it comes from. A "do not" is a place where the product breaks the rule today; it stays listed here until the screen is fixed. The color rules have their own examples on [color meaning](/brand/color).

## Words

| Do                                                                                                                                                                                                                                                                       | Do not                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Use "close" for the whole act. The landing headline says "Close the account." (`apps/web/app/(marketing)/page.tsx`), and the execution screen's button says "Sign & execute close" (`apps/web/components/execution/ExecutionWizard.tsx`).                                | Use "merge" for the whole act. The completion screen offers "Merge another account" (`apps/web/components/complete/CompletionReceipt.tsx`), and the app's history panel and its navigation button are called "Merge history" (`apps/web/components/history/HistoryPanel.tsx`, `apps/web/components/layout/NavBar.tsx`). Merge is only the final on-chain operation; they should read "Close another account" and "Close history". |
| State irreversibility once, where the user decides. Before signing, the execution screen asks the user to tick "I understand this permanently closes the account and sends its balance to the destination above." (`apps/web/components/execution/ExecutionWizard.tsx`). | Call it irreversible in a caution color. The account entry screen's "Irreversible action." notice is amber (`apps/web/app/[network]/page.tsx`); see [red is irreversible or error](/brand/color#red-is-irreversible-or-error).                                                                                                                                                                                                    |
| Keep protocol terms and gloss them, linking to the [glossary](/reference/glossary).                                                                                                                                                                                      | Replace a protocol term with a friendlier invented one the user will not find in a wallet or explorer.                                                                                                                                                                                                                                                                                                                            |

## Numbers

| Do                                                                                                                                                                    | Do not                                                                                                                                                                                                                                                           |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Show amounts in tabular numerals with the asset code. The network statistics show "XLM recovered" with `tabular-nums` (`apps/web/components/stats/NetworkStats.tsx`). | Show an amount in proportional figures. The plan screen's "Estimated received at destination" amount is set in the display face without tabular numerals, so its digits do not align with the rows above it (`apps/web/components/plan/AccountSummaryCard.tsx`). |
| Name the source and date of a number that can change.                                                                                                                 | Publish a count, a total or a security claim with no mechanism, source or date behind it.                                                                                                                                                                        |

## Buttons

| Do                                                                                                                                                     | Do not                                                                                                                                                                                                                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Give a screen one solid button, the primary variant of `Button` (`apps/web/components/ui/button.tsx`), and make every other action secondary or ghost. | Put two solid buttons side by side. The landing hero has two solid gold buttons, "Analyze account" and "Open the app" (`apps/web/components/marketing/HeroAccountInput.tsx`, `apps/web/app/(marketing)/page.tsx`), which also breaks [gold is recovered value only](/brand/color#gold-is-recovered-value-only). |
| Use the danger variant for the one action that cannot be undone, as "Sign & execute close" does (`apps/web/components/execution/ExecutionWizard.tsx`). | Use the danger variant for an action that can be undone or retried.                                                                                                                                                                                                                                             |

## Logo

| Do                                                                                  | Do not                                                                                 |
| ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Use `docs/logo/dark.svg` on the dark page background, as the docs site header does. | Recolor, stretch, rearrange or add effects to the logo. See [logo usage](/brand/logo). |
